# บทที่ 4 การออกแบบเกม (Game Design)

> **ไฟล์:** `docs/04-chapter-4-game-design.md` · **ผู้รับผิดชอบ:** Game Designer + Game Developer + Story Designer
> **หลักการ:** ทุกกลไกผูกกับผลลัพธ์การเรียนรู้ (บทที่ 3.4) — "ยิงสนุก = สะกดถูก"

---

## 4.1 แนวคิดหลัก (High Concept) และประเภทเกม

> **หนึ่งประโยค:** "เอเลี่ยนมอนสเตอร์ถือคำศัพท์ที่ขาดตัวสะกดบุกโลก — ผู้เล่นยิงกระสุนมาตราตัวสะกด (แป้น 1–8)
> ให้ถูกต้องเพื่อเปลี่ยนพวกมันเป็นมิตร ก่อนที่ยานของตัวเองจะถูกทำลาย ภายในเวลา 3 นาที"

| องค์ประกอบ | คำตอบ |
|---|---|
| **ประเภทเกม** | Shooter Defense + Educational (Serious Game) |
| **มุมมอง** | 2D side-view — มอนสเตอร์เดินจากขอบจอเข้ามาทางซ้าย/ขวา ยานผู้เล่นอยู่ตรงกลาง/ล่าง |
| **ผู้เล่น** | เดี่ยว (Single-player) + อันดับ Hall of Fame 10 อันดับ |
| **แพลตฟอร์ม** | เว็บ (PWA) — เมาส์/คีย์บอร์ดหลัก, สัมผัส (แท็บเล็ต), AR (กล้อง) |
| **โทน** | Sci-Fi อวกาศ ตื่นเต้นเร้าใจ เหมาะกับเด็ก 8–10 ปี |
| **เวลา/รอบ** | 3 นาที |

## 4.2 เรื่องราวและโครงเรื่อง (Story & Narrative)

**โครงเรื่อง 3 องก์:**

1. **องก์ที่ 1 — การบุก:** ยานอวกาศขนาดยักษ์ปล่อยมอนสเตอร์จำนวนมากลงสู่โลก มอนสเตอร์แต่ละตัวถือ
   "บัตรคำ" ที่ตัวสะกดถูกทำลาย (ไฟกะพริบ) — ถ้าไม่มีใครซ่อม บัตรคำจะระเบิดทำลายเมือง
2. **องก์ที่ 2 — การต่อสู้:** ผู้เล่น (นักบินกองกำลังพิทักษ์) ยิงกระสุนมาตราตัวสะกดถูกต้อง → มอนสเตอร์
   เปลี่ยนร่างเป็นมิตรและเข้าร่วมทีม; ยิงผิด → มอนสเตอร์ชะงักชั่วครู่และโกรธ (เดินไวขึ้นชั่วคราว)
3. **องก์ที่ 3 — จุดไคลแมกซ์:** บอส "ราชามอนสเตอร์สะกดหลง" ปรากฏ (คำไม่ตรงมาตรายากสุด) →
   ผู้เล่นเอาชนะด้วยการสะกดให้ถูกทั้งหมด → เก็บชิ้นส่วนอัปเกรดยาน → พิธีประกาศอันดับใน Hall of Fame

**โทนเสียง/อารมณ์:** เร้าใจ เร็ว แต่ไม่น่ากลัวเกินไปสำหรับเด็ก — มอนสเตอร์หน้าตาตลก ๆ Neon สีสันสดใส

## 4.3 ตัวละครและมอนสเตอร์

| ตัวละคร | บทบาท |
|---|---|
| **ผู้เล่น (นักบินกองกำลังพิทักษ์)** | ควบคุมยาน ยิงกระสุนมาตรา |
| **ยานอวกาศ "ผู้พิทักษ์-1"** | ยานของผู้เล่น — อัปเกรดได้ด้วยชิ้นส่วน (ปืน, โล่, เครื่องยนต์) |
| **มอนสเตอร์ชนิดต่าง ๆ** | มีรูปร่าง/ความเร็ว/HP ต่างกัน (OOP คลาสย่อย — ดูบทที่ 7.3) |
| **ราชามอนสเตอร์ (Boss)** | บอสท้ายเกม — ต้องสะกดถูกหลายคำติดต่อกัน |

**คลาสย่อยมอนสเตอร์ (ตัวอย่าง):**

| คลาส | ลักษณะ | บทบาทในการออกแบบ |
|---|---|---|
| `WalkerMonster` | เดินช้า ตัวเล็ก HP ต่ำ | ฝึกพื้นฐาน (ด่าน 1–3) |
| `RunnerMonster` | เดินเร็ว ตัวเล็ก | เพิ่มความกดดัน (ด่าน 4+) |
| `TankMonster` | เดินช้า HP สูง ต้องยิงซ้ำ | คำที่ผิดบ่อย — ให้ฝึกซ้ำ |
| `BossMonster` | ใหญ่สุด ท้าทายหลายคำติดต่อ | ไคลแมกซ์ด่านสุดท้าย |

> 🔗 **รายการตัวละครฉบับสมบูรณ์** (หน้าตา สี สถิติ แอนิเมชัน บุคลิก) ดูที่ [`design/characters.md`](../design/characters.md)

## 4.4 โลกของเกมและด่าน (Levels)

| ด่าน | ชื่อ | เนื้อหา/มาตรา | ความยาก (ความเร็ว/ไม่ตรงมาตรา) |
|---|---|---|---|
| 1 | ฐานฝึกยิง | แม่กก, กด (ตรงมาตรา) | ช้ามาก · ตรงมาตรา 100% |
| 2 | สนามฝึก 2 | กบ, กน (ตรงมาตรา) | ช้า · ตรง 100% |
| 3 | ฝึก 3 | กม, เกย, เกอว + แม่กา | ปานกลาง · ตรง 80% |
| 4 | ด่านป่าเมือง | ผสมตรงมาตรา + ไม่ตรงมาตราง่าย (ข, ค) | ปานกลาง · ตรง 50% |
| 5 | เมืองมอนสเตอร์ | ไม่ตรงมาตรา: จ ช ซ ศ ษ ส (แม่กด) | เร็วขึ้น · ไม่ตรง 50% |
| 6 | ฐานทัพมอนสเตอร์ | ไม่ตรงมาตรา: ป พ ภ ฟ (แม่กบ), ร ล ญ ฬ (แม่กน) | เร็ว · ไม่ตรง 70% |
| 7 | พรมแดนอวกาศ | คำพ้องเสียง + ไม่ตรงมาตรายาก | เร็ว · ไม่ตรง 80% |
| 8 | บอส: ราชามอนสเตอร์สะกดหลง | ผสมทุกมาตรา (ยากสุด) | เร็วสุด + บอส |

**โครงสร้าง 1 รอบ (3 นาที):** คลื่นมอนสเตอร์ 4–6 คลื่น → บอสย่อย/บอส (ด่าน 8) → สรุปคะแนน + ชิ้นส่วนอัปเกรด

## 4.5 กลไกหลักของเกม (Core Loop)

```
มอนสเตอร์ถือบัตรคำเดินเข้ามา → ผู้เล่นอ่านคำ (ตัวสะกดกะพริบ/หายไป)
   → เลือกกระสุนมาตรา (แป้น 1–8 / คลิกปุ่มกระสุน) → ยิง
      ├─ ✅ ถูก: มอนสเตอร์เปลี่ยนเป็นมิตร + คะแนน + เอฟเฟกต์ระเบิดสีเขียว
      └─ ❌ ผิด: มอนสเตอร์ชะงัก 2–3 วิ + คำใบ้สีแดง + คะแนนติดลบเล็กน้อย
→ คลื่นถัดไป (ยากขึ้น) → จบ 3 นาที → สรุปคะแนน/ความแม่นยำ → ชิ้นส่วนอัปเกรด/อันดับ
```

**กฎสำคัญ:**
- ยิงผิดไม่มีผลต่อมอนสเตอร์ชนิดอื่น (ไม่ลงโทษหนัก) — เน้นให้เรียนรู้จากคำใบ้
- คำศัพท์ไม่ซ้ำกันในรอบเดียวกัน (สุ่มจากธนาคารคำ, ป้องกันการจำตำแหน่ง)
- ยานมี HP — มอนสเตอร์ถึงฐาน 3 ตัว = จบรอบ (หรือใช้โหมดผ่อนปรน: ไม่มี HP)

## 4.6 การควบคุม: Mouse / Keyboard (1–8) / AR

| วิธี | รายละเอียด |
|---|---|
| **Mouse (หลัก)** | เลื่อนเมาส์เล็งเป้า · คลิกซ้ายยิง · คลิกที่ปุ่มกระสุนมาตราเพื่อสลับชนิด (หรือคลิกขวาเลื่อน) |
| **Keyboard** | **1–8 เลือกกระสุนมาตรา** (1=กา, 2=กก, 3=กด, 4=กบ, 5=กน, 6=กม, 7=เกย, 8=เกอว) · Space ยิง · Esc เปิด Settings |
| **แท็บเล็ต** | แตะปุ่มกระสุน 8 ปุ่ม + แตะยิง (โหมดสัมผัส) |
| **AR (โหมดเสริม)** | สแกนการ์ดมอนสเตอร์ (Marker AR) → มอนสเตอร์ 3D/2D ปรากฏบนโต๊ะ → เล็งด้วยการเอียงกล้อง/แตะเพื่อยิงกระสุนมาตรา — ใช้ AR.js, ทำงานแบบ Marker-based |

> **Fallback:** ไม่มีกล้อง/ไม่อนุญาต → เล่นโหมดจอปกติได้เต็มรูปแบบ (AR เป็นโหมดเสริม)

## 4.7 ระบบช่วยเหลือเมื่อตอบผิด (Hint System)

| ระดับ | ลำดับการช่วยเหลือ | ตัวอย่าง |
|---|---|---|
| 1 | มอนสเตอร์ชะงัก 2–3 วินาที | ตัวละครหยุด กระพริบ |
| 2 | คำใบ้สีแดงเหนือหัวมอนสเตอร์ | "คำนี้ออกเสียงเหมือน **ก** สะกด" |
| 3 | เน้นเสียงที่ถูกต้อง (ซ้ำได้) | เสียงพูดสะกด "สอ-ุ-ก" + แสดงชุดตัวเลือกแคบลง |
| 4 | (โหมดผ่อนปรน) เฉลยเต็ม | แสดงตัวสะกดที่ถูก + เหตุผล "ข = แม่กก (ไม่ตรงมาตรา)" |

**หลักการ:** คำใบ้ค่อยเป็นค่อยไป (Progressive Hints) — ผู้เรียนได้คิดก่อน เห็นเหตุผลเมื่อผิด
และคำใบ้ทุกอันเป็น **ข้อความ + เสียง** (รองรับการปิดเสียง)

## 4.8 ระบบรางวัล: ชิ้นส่วนอัปเกรดยานอวกาศ

| ชิ้นส่วน | ผลต่อเกม | วิธีได้ |
|---|---|---|
| **เครื่องยนต์เทอร์โบ** | มอนสเตอร์เดินช้าลง 10% / ลดเวลาชะงักหลังผิด | ผ่านด่านด้วยความแม่นยำ ≥ 70% |
| **ปืนเลเซอร์คู่** | ยิงเร็วขึ้น (กระสุน 2 นัด/วินาที) | ผ่านด่าน 4, 6, 8 |
| **โล่พลังงาน** | ยานทนมอนสเตอร์ถึงฐานได้ +1 ตัว | สะสมคะแนนรวมถึงเกณฑ์ |
| **เซนเซอร์แม่นยำ** | ขยายหน้าต่างเวลาให้คำใบ้ (โหมดฝึก) | เล่นครบ 10 รอบ |

**นอกจากนี้:** คะแนน/รอบ, ดาว 1–3 ดวงต่อด่าน, เหรียญตรา (เช่น "ผู้พิทักษ์แม่กด") และ
**Hall of Fame 10 อันดับ** (ชื่อในเกม + คะแนน + ด่านสูงสุด)

## 4.9 การไต่ระดับความยากและสมดุลเกม

| ปัจจัย | ด่านต่ำ → ด่านสูง |
|---|---|
| ความเร็วมอนสเตอร์ | ช้า → เร็ว (ปรับตาม Settings/โหมด) |
| สัดส่วนไม่ตรงมาตรา | 0% → 70–80% |
| ความยาว/จำนวนพยางค์ของคำ | 1 พยางค์ → 2–3 พยางค์ |
| จำนวนคลื่น/รอบ | 4 → 6 คลื่น + บอส |
| คำใบ้ | เร็ว/ชัดเจน → จำกัดจำนวน (โหมดท้าทาย) |

**Dynamic Difficulty (อย่างง่าย):** ระบบติดตามอัตราความแม่นยำของผู้เล่น — ถูกเกิน 90% → เพิ่มความเร็ว;
ผิดเกิน 60% → ลดความเร็ว/ให้คำใบ้ระดับ 2 ทันที (รักษา Flow — ไม่เบื่อ/ไม่เครียดเกินไป)

## 4.10 แผนผังขั้นตอนการเล่น (Game Flow)

```
หน้าหลัก (เริ่ม / โหมด AR / การ์ด AR / ตั้งค่า / Hall of Fame)
   → เลือกด่าน (ล็อกตามความคืบหน้า)
   → Intro สั้น (3–5 วินาที)
   → เกมหลัก 3 นาที: คลื่นมอนสเตอร์ → เลือกกระสุน → ยิง → ผลป้อนกลับ/คำใบ้
   → สรุปรอบ: คะแนน, ความแม่นยำ, ดาว, ชิ้นส่วนอัปเกรด
   → โรงเก็บยาน (อัปเกรด) / บันทึกอันดับ → หน้าหลัก
```
