## คำนำ

เอกสารเล่มนี้จัดทำขึ้นเพื่อใช้เป็น **"หนังสือโครงการ"** ฉบับสมบูรณ์ของเกม **กองกำลังพิทักษ์ตัวสะกด (Monster Speller)**
เกมแนว Shooter Defense ที่เปลี่ยนการฝึกสะกดคำภาษาไทย (มาตราตัวสะกด) ให้เป็นการผจญภัยสุดตื่นเต้น —
เอเลี่ยนมอนสเตอร์ที่มีคำศัพท์แต่ขาดตัวสะกดบุกโลก ผู้เล่นต้องยิงกระสุนมาตราตัวสะกดให้ถูกต้องเพื่อเปลี่ยนพวกมันเป็นมิตร

เอกสารจัดโครงสร้างเลียนแบบหนังสือวิชาการ: **สารบัญ รายการบท รายการหัวข้อในแต่ละบท และบรรณานุกรม**
จัดทำเป็น **1 บทต่อ 1 ไฟล์** เพื่อความสะดวกในการติดตามผ่าน **บอร์ด Kanban** (แต่ละบท = งานที่ติดตามได้)
และปรับปรุงได้ตามหลักการ Agile

## สารบัญ

### บทที่ 1 บทนำ
- 1.1 ความเป็นมาและความสำคัญ
- 1.2 ปัญหาและความจำเป็นของโครงการ
- 1.3 วัตถุประสงค์ของโครงการ
- 1.4 กรอบแนวคิดของโครงการ
- 1.5 ขอบเขตของโครงการ
- 1.6 นิยามศัพท์เฉพาะ
- 1.7 ประโยชน์ที่คาดว่าจะได้รับ

### บทที่ 2 ทบทวนวรรณกรรมและทฤษฎีที่เกี่ยวข้อง
- 2.1 ทฤษฎีการเรียนรู้
- 2.2 การเรียนรู้โดยใช้เกมเป็นฐาน (Game-Based Learning)
- 2.3 แรงจูงใจและเกมมิฟิเคชัน
- 2.4 การสอนภาษาไทย: การแจกลูก–สะกดคำและมาตราตัวสะกด
- 2.5 เทคโนโลยีความจริงเสริม (AR) ในการศึกษา
- 2.6 การออกแบบระบบการเรียนการสอน (ADDIE / Backward Design / Gagné)
- 2.7 งานวิจัยที่เกี่ยวข้อง
- 2.8 กรอบแนวคิดการวิจัย

### บทที่ 3 การวิเคราะห์ผู้เรียนและเนื้อหา
- 3.1 กลุ่มเป้าหมายและคุณลักษณะผู้เรียน
- 3.2 การวิเคราะห์หลักสูตรและตัวชี้วัด
- 3.3 การวิเคราะห์เนื้อหา: 8 มาตรา (ตรง/ไม่ตรงมาตรา) และธนาคารคำศัพท์
- 3.4 ผลลัพธ์การเรียนรู้ (Learning Outcomes)
- 3.5 สภาพแวดล้อมการใช้งาน
- 3.6 ข้อจำกัดและเงื่อนไขของโครงการ

### บทที่ 4 การออกแบบเกม
- 4.1 แนวคิดหลัก (High Concept) และประเภทเกม
- 4.2 เรื่องราวและโครงเรื่อง (Story & Narrative)
- 4.3 ตัวละครและมอนสเตอร์
- 4.4 โลกของเกมและด่าน (Levels)
- 4.5 กลไกหลักของเกม (Core Loop): ยิงกระสุนมาตราตัวสะกด
- 4.6 การควบคุม: Mouse / Keyboard (1–8) / AR (สแกนการ์ด)
- 4.7 ระบบช่วยเหลือเมื่อตอบผิด (Hint System)
- 4.8 ระบบรางวัล: ชิ้นส่วนอัปเกรดยานอวกาศ
- 4.9 การไต่ระดับความยากและสมดุลเกม
- 4.10 แผนผังขั้นตอนการเล่น (Game Flow)

### บทที่ 5 การออกแบบการเรียนรู้และการประเมินผล
- 5.1 แผนการจัดการเรียนรู้ (ตัวอย่าง 1 คาบ)
- 5.2 กลยุทธ์การเรียนการสอนในเกม (Gagné 9 เหตุการณ์)
- 5.3 การออกแบบแบบทดสอบก่อน–หลังเรียน (Pre-test / Post-test)
- 5.4 การประเมินระหว่างเล่น (In-game Assessment)
- 5.5 การประเมินแรงจูงใจและความพึงพอใจ

### บทที่ 6 การออกแบบ UI/UX และกราฟิก
- 6.1 อัตลักษณ์ภาพ (Art Direction): 2D Neon Sci-Fi
- 6.2 หลักการออกแบบ UX สำหรับเด็กอายุ 8–10 ปี
- 6.3 โครงสร้างหน้าจอ (Screen Map) และ Modal
- 6.4 ระบบไอคอน ป้าย และคำแนะนำ
- 6.5 การออกแบบเพื่อทุกคน (Accessibility)
- 6.6 รายการสินทรัพย์กราฟิกและเครื่องมือ

### บทที่ 7 สถาปัตยกรรมระบบและเทคโนโลยี
- 7.1 สถาปัตยกรรมโดยรวม
- 7.2 เทคโนโลยีและเหตุผลการเลือกใช้
- 7.3 การออกแบบเชิงวัตถุ (OOP): คลาส Monster และระบบเกม
- 7.4 โครงสร้างโปรเจกต์ (Folder Structure)

- 7.6 การเรนเดอร์ Sprite: Canvas / CSS
- 7.7 ประสิทธิภาพและข้อจำกัดของอุปกรณ์
- 7.8 ความปลอดภัยและความเป็นส่วนตัว

### บทที่ 8 แผนการพัฒนาซอฟต์แวร์
- 8.1 วงจรการพัฒนา (Sprints)
- 8.2 Product Backlog ตัวอย่าง
- 8.3 Definition of Done (DoD)
