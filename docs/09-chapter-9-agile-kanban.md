# บทที่ 9 การจัดการโครงการด้วย Agile Kanban

> **ไฟล์:** `docs/09-chapter-9-agile-kanban.md` · **ผู้รับผิดชอบ:** Scrum Master / Project Manager
> **เครื่องมือแนะนำ:** GitHub Projects / GitLab Boards / Trello

---

## 9.1 หลักการ Agile

อ้างอิง **Agile Manifesto (Beck et al., 2001)** — น้ำหนักเน้นที่:
1. **บุคคลและการปฏิสัมพันธ์** มากกว่ากระบวนการและเครื่องมือ
2. **ซอฟต์แวร์ที่ทำงานได้** มากกว่าเอกสารที่ครอบคลุม
3. **การตอบสนองต่อการเปลี่ยนแปลง** มากกว่าการทำตามแผนอย่างเคร่งครัด
4. **ความร่วมมือกับผู้ใช้ (ครู/นักเรียน)** มากกว่าการเจรจาสัญญา

## 9.2 เหตุผลที่เลือก Kanban (แบบผสม Scrum: "Kanban + Sprint")

| เหตุผล | คำอธิบาย |
|---|---|
| งานหลากหลาย (ดีไซน์, โค้ด, เนื้อหาคำศัพท์, AR, เอกสาร) | Kanban ปล่อยงานไหลลื่น ไม่บังคับขนาดงานเท่ากัน |
| เห็นภาพงานทั้งระบบตลอดเวลา | บอร์ดเดียวแสดง Backlog → Done |
| มีงานแทรกต่อเนื่อง (แก้บั๊ก, ปรับคำศัพท์, เนื้อหาใหม่) | WIP Limits ป้องกันงานท่วมทีมเล็ก |
| ยังรักษาจังหวะ Sprint (2 สัปดาห์) | ใช้ Scrum Ceremonies + Kanban board ร่วมกัน |

## 9.3 โครงสร้างบอร์ด Kanban และ WIP Limits

```
┌────────────┬──────────┬─────────────┬─────────────┬──────────────┬────────────┐
│ 📥 Backlog │ 🟡 Ready │ 🟠 In Progress │ 🔵 Review │ 🟣 QA/Test  │ ✅ Done   │
│ (ทุกไอเดีย) │ (พร้อมทำ)│ (กำลังทำ)     │ (รีวิวโค้ด)  │ (ทดสอบ/แก้)  │ (เสร็จ)   │
│            │          │              │             │              │            │
│ WIP: ∞     │ WIP: 5   │ WIP: 3/ทีม   │ WIP: 3      │ WIP: 2       │ ∞          │
└────────────┴──────────┴─────────────┴─────────────┴──────────────┴────────────┘
```

**กฎ WIP:** ทีม 5–7 คน → In Progress ≤ 3 การ์ด, Review ≤ 3, QA ≤ 2 — บังคับให้ "ทำเสร็จ" ก่อนเริ่มใหม่;
การ์ดติดขัด (Blocked) ตั้งธง 🚩 และแก้ภายใน 24 ชม. ผ่าน Daily Standup

## 9.4 บทบาทของทีม

| บทบาท | ผู้รับผิดชอบ | ภารกิจหลัก |
|---|---|---|
| **Product Owner** | ครูภาษาไทย/นักวิชาการ | ลำดับ Backlog, ยืนยันเนื้อหาคำศัพท์/มาตรา, ตัดสินใจขอบเขต |
| **Scrum Master / PM** | ผู้จัดการโครงการ | กระบวนการ Kanban, WIP, ขจัดอุปสรรค, อำนวยประชุม |
| **Game Developer** | นักพัฒนา Vue/TS/Canvas | GameEngine, OOP Monster, Bullet, WaveManager |
| **AR Engineer** | นักพัฒนา AR.js | โหมด AR, การ์ดมอนสเตอร์, การผสานกับเกม |
| **UI/UX & Graphic Designer** | นักออกแบบ | Sprite, Neon art direction, Modal, สินทรัพย์, accessibility |
| **Content Specialist** | ครูภาษาไทย | ธนาคารคำ 200+, คำใบ้/เฉลย, ใบงาน, คู่มือครู, ตรวจ IOC |
| **QA Tester** | นักทดสอบ (+ นักเรียนกลุ่มทดลอง) | ทดสอบฟีเจอร์, ข้ามอุปกรณ์, Pilot |

> ทีมย่อม (3–4 คน) → รวมบทบาท เช่น Game Developer + AR Engineer

## 9.5 พิธีกรรมของทีม (Ceremonies)

| พิธีกรรม | ความถี่ | เวลา | เนื้อหา |
|---|---|---|---|
| **Daily Standup** | ทุกวัน | 15 นาที | เมื่อวาน/วันนี้/อุปสรรค (เน้นบอร์ด) |
| **Sprint Planning** | ทุก 2 สัปดาห์ | 1–2 ชม. | เลือกการ์ดเข้าสู่ Ready + Sprint Goal |
| **Sprint Review (Demo)** | ทุก 2 สัปดาห์ | 1 ชม. | โชว์ชิ้นงาน Done ให้ PO/ครู/นักเรียนเห็น |
| **Retrospective** | ทุก 2 สัปดาห์ | 45 นาที | Start/Stop/Continue + 1–2 ข้อปรับปรุง |
| **Backlog Refinement** | 1 ครั้ง/สัปดาห์ | 30–45 นาที | แยก/จัดลำดับ/ประมาณการ User Stories |

## 9.6 รูปแบบการ์ดงาน (Card Template)

```
📌 [US-XX] (ประเภท) — ชื่อเรื่องสั้น
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📝 รายละเอียด: ตาม User Story / Acceptance Criteria
🎯 Sprint: 3   📊 คะแนน: 5   🔥 ความสำคัญ: Must
👤 ผู้รับผิดชอบ: @dev1
✅ DoD: ลิงก์บทที่ 8.3
🚩 Blockers: —
🔗 เอกสารที่เกี่ยวข้อง: docs/07-…
```

**ประเภทการ์ด:** 🎨 ดีไซน์ · 👨‍💻 โค้ด · 📚 เนื้อหา (คำศัพท์/คำใบ้) · 🧪 ทดสอบ · 📄 เอกสาร · 🐛 บั๊ก

## 9.7 เมตริกและการปรับปรุง (Metrics)

| เมตริก | นิยาม | เป้าหมาย |
|---|---|---|
| **Cycle Time** | In Progress → Done | < 3 วัน/การ์ด |
| **Lead Time** | Backlog → Done | < 2 สัปดาห์ |
| **Throughput** | การ์ด Done/สัปดาห์ | ≥ 4 การ์ด/สัปดาห์ |
| **CFD** | แนวโน้มงานค้างแต่ละคอลัมน์ | ไม่พองตัวใน In Progress |
| **% Scope Changed** | งานที่เปลี่ยนหลัง Sprint | < 30% |

**ปรับปรุงต่อเนื่อง (Kaizen):** ทุก Retrospective ดูเมตริก + เลือกมาตรการ เช่น ลด WIP, แยก Epic,
pair programming, test-first สำหรับระบบคะแนน/มาตรา

## 9.8 ตัวอย่างการ์ดงานจริง (เริ่ม Sprint 1)

| การ์ด | ประเภท | Sprint | สถานะ |
|---|---|---|---|
| US-01 ยิงมอนสเตอร์ด้วยเมาส์ (เล็ง+คลิก) | 👨‍💻 | 1 | 🟠 In Progress |
| US-02 เลือกกระสุนมาตรา 1–8 (Keyboard) | 👨‍💻 | 1 | 🟡 Ready |
| US-03 แสดงบัตรคำบนมอนสเตอร์ (ตัวสะกดกะพริบ) | 👨‍💻 | 1 | 🟡 Ready |
| Sprite sheet มอนสเตอร์ Walker (เดิน/ระเบิด/มิตร) | 🎨 | 1 | 📥 Backlog |
| ธนาคารคำ ด่าน 1–2 (แม่กก/กด ตรงมาตรา) + ตรวจ IOC | 📚 | 1 | 🔵 Review |
| เทมเพลตการ์ด AR มอนสเตอร์ (พิมพ์) | 🎨 | 1 | 📥 Backlog |
| Unit test ระบบตรวจมาตรา (ถูก/ผิด) | 🧪 | 1 | 📥 Backlog |
