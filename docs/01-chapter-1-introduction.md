## 1.1 ความเป็นมาและความสำคัญ

**มาตราตัวสะกด** เป็นรากฐานสำคัญของการอ่านออกเขียนได้ภาษาไทย หากนักเรียนจำแนกมาตราตัวสะกดไม่ได้
ย่อมส่งผลต่อการเขียนสะกดคำที่ผิดพลาดต่อเนื่องไปจนถึงระดับสูงขึ้น อย่างไรก็ตาม ตัวสะกดภาษาไทยมีลักษณะพิเศษ —
**ตัวสะกดไม่ตรงมาตรา** (เช่น ข ค ฆ สะกดเสียง ก) ที่ไม่ตรงกับรูปตัวอักษร ทำให้นักเรียนชั้นประถมเกิดความสับสน
และสะกดผิดเป็นจำนวนมาก

การฝึกสะกดคำแบบดั้งเดิม (ท่องจำ/คัดคำ) มักเป็นกิจกรรมซ้ำ ๆ ที่นักเรียนขาดแรงจูงใจ โครงการนี้จึงเสนอ
**เกมการศึกษาแนว Shooter Defense** ชื่อ **"กองกำลังพิทักษ์ตัวสะกด (Monster Speller)"** ที่เปลี่ยน
การฝึกมาตราตัวสะกดให้เป็นเกมยิงมอนสเตอร์ธีมไซไฟอวกาศ เร้าใจ สีสัน Neon —
โดยผู้เล่นต้องเลือกยิงกระสุนมาตราตัวสะกดให้ถูกต้อง (แป้น 1–8 / เมาส์ / AR) เพื่อเปลี่ยนมอนสเตอร์ให้เป็นมิตร
ภายในเวลา 3 นาทีต่อรอบ

## 1.2 ปัญหาและความจำเป็นของโครงการ

| # | ปัญหา | ผลกระทบ |
|---|---|---|
| P1 | นักเรียนสับสน **ตัวสะกดไม่ตรงมาตรา** (เสียงเหมือนแต่รูปต่าง) | เขียนสะกดผิดเป็นประจำ |
| P2 | การฝึกแบบท่องจำ/คัดคำ ซ้ำ ๆ ไม่ดึงดูด | นักเรียนขาดแรงจูงใจ เบื่อหน่าย |
| P3 | ขาดสื่อฝึกที่ให้ **ผลป้อนกลับทันที** รายบุคคล | ครูตรวจไม่ทัน ข้อผิดพลาดฝังแน่น |
| P4 | การประเมินเน้นความจำ ไม่สะท้อนความเข้าใจเชิงจำแนกมาตรา | ไม่รู้ว่านักเรียนผิดมาตราใด |

## 1.3 วัตถุประสงค์ของโครงการ

1. เพื่อออกแบบและพัฒนาเกม **Monster Speller** ด้วย **Vue 3 + Pinia + Canvas/CSS Sprite + AR.js**
   สำหรับการเรียนรู้มาตราตัวสะกดระดับชั้น ป.3–4
2. เพื่อศึกษาผลของเกมต่อ **ผลสัมฤทธิ์การเขียนสะกดคำ** (คะแนนก่อน–หลังเรียน)
3. เพื่อศึกษา **แรงจูงใจและความพึงพอใจ** ของผู้เรียนที่มีต่อเกม
4. เพื่อนำเสนอ **แนวปฏิบัติการจัดการโครงการเกมการศึกษาแบบ Agile + Kanban**

## 1.5 ขอบเขตของโครงการ

**ด้านเนื้อหา:** มาตราตัวสะกด 8 มาตรา (แม่กา กก กด กบ กน กม เกย เกอว) — ทั้งตัวสะกดตรงมาตราและไม่ตรงมาตรา
พร้อมธนาคารคำศัพท์ระดับชั้น ป.3–4

**ด้านเทคโนโลยี:**
- เกมหลัก 2D บนเว็บ — **Vue 3 + Pinia** (state), **Canvas/CSS Sprite** (แอนิเมชันเดิน/ระเบิด)
- **OOP** — คลาส `Monster` (และคลาสย่อยตามชนิดมอนสเตอร์)
- การควบคุม: **Mouse** (เล็ง/ยิง), **Keyboard 1–8** (เลือกกระสุนมาตรา), **AR** (สแกนการ์ดมอนสเตอร์บนโต๊ะ ผ่าน AR.js)
- **Modal Settings** (เสียง/ความเร็ว) และ **Modal Hall of Fame** (10 อันดับ)

**ด้านระยะเวลา:** 16 สัปดาห์ (4 เดือน) = 8 Sprints · **เวลาเล่นต่อรอบ:** 3 นาที

**นอกขอบเขต (v1):** ระบบผู้เล่นหลายคนออนไลน์, แอปเนทีฟ, การเชื่อมระบบทะเบียนนักเรียนอัตโนมัติ, เนื้อหามาตราอื่น ๆ
(เช่น คำที่ประวิสรรชนีย์, อักษรนำ) — พิจารณาในบทที่ 12

## 1.6 นิยามศัพท์เฉพาะ

| ศัพท์ | นิยาม |
|---|---|
| **มาตราตัวสะกด** | หมวดของคำตามเสียงตัวสะกด 8 มาตรา (กา กก กด กบ กน กม เกย เกอว) |
| **ตัวสะกดตรงมาตรา** | ตัวสะกดที่รูปตรงกับเสียงมาตรา เช่น "มาก" (ก = แม่กก) |
| **ตัวสะกดไม่ตรงมาตรา** | ตัวสะกดที่รูปต่างแต่เสียงตรงมาตรา เช่น "เลข" (ข ออกเสียง ก = แม่กก) |
| **Shooter Defense** | แนวเกมยิงเป้า/ป้องกันฐาน — มอนสเตอร์บุกเข้ามา ผู้เล่นยิงหยุดมัน |
| **Sprite** | ภาพ 2 มิติ (ชุดเฟรม) สำหรับแอนิเมชัน เช่น เดิน, ระเบิด |
| **Hall of Fame** | ตารางจัดอันดับ 10 คะแนนสูงสุด |
| **PWA** | เว็บแอปที่ติดตั้งได้และเล่นแบบออฟไลน์บางส่วน |

## 1.7 ประโยชน์ที่คาดว่าจะได้รับ

1. นักเรียนจำแนกมาตราตัวสะกดตรง/ไม่ตรงมาตราได้ถูกต้องขึ้น → เขียนสะกดคำผิดน้อยลง
2. นักเรียนมีแรงจูงใจและเจตคติที่ดีต่อวิชาภาษาไทย
3. ครูได้สื่อฝึกทักษะที่ให้ผลป้อนกลับทันทีพร้อมรายงานแนวโน้มการผิดรายมาตรา
4. ทีมได้องค์ความรู้การออกแบบเกมฝึกทักษะภาษา (Shooter Defense + AR) และแนวทาง Agile Kanban
5. ต่อยอดเป็นชุดสื่อ "เกมสะกดคำไทย" สำหรับทุกระดับชั้นและมาตราในอนาคต
