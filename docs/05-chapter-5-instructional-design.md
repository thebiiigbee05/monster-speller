## 5.1 แผนการจัดการเรียนรู้ (ตัวอย่าง 1 คาบ — ภาษาไทย ป.3)

| รายการ | รายละเอียด |
|---|---|
| **วิชา/ชั้น** | ภาษาไทย ป.3 (บูรณาการเทคโนโลยี) |
| **เวลา** | 60 นาที |
| **มาตรฐาน/ตัวชี้วัด** | ท 4.1 หลักการใช้ภาษาไทย — การสะกดคำ/มาตราตัวสะกด |
| **สื่อ** | เกม Monster Speller (คอมพิวเตอร์/แท็บเล็ต), การ์ด AR มอนสเตอร์, ใบงาน |
| **ขั้นตอน** | ดูตารางด้านล่าง |

| ช่วงเวลา | กิจกรรม | บทบาทเกม (Gagné) |
|---|---|---|
| 5 นาที | ครูทบทวนเสียงมาตรา + ตั้งคำถาม ("คำว่า เลข ตัวสะกดคืออะไร ออกเสียงมาตราไหน?") | 1. กระตุ้นความสนใจ |
| 5 นาที | แจ้งจุดประสงค์ + สาธิตวิธีเลือกกระสุน (1–8) และยิง | 2. แจ้งวัตถุประสงค์ |
| 15 นาที | ผู้เรียนเล่นเกม 3–4 รอบ (คนละเครื่อง) — ครูสังเกต | 3–6. นำเสนอ/ชี้นำ/ปฏิบัติ |
| 10 นาที | กิจกรรมกลุ่ม: ใช้การ์ด AR สแกนมอนสเตอร์ + ช่วยกันบอกมาตรา | 5–6. ชี้แนะ/ปฏิบัติร่วม |
| 10 นาที | แบบทดสอบย่อยในเกม (โหมด "ภารกิจสอบ") คะแนนบันทึกอัตโนมัติ | 7–8. ผลป้อนกลับ/ประเมิน |
| 10 นาที | ครูสรุปจาก Dashboard (มาตราใดผิดมากสุด) + ใบงานซ่อมเสริม | 9. การจดจำ/ถ่ายโอน |

## 5.2 กลยุทธ์การเรียนการสอนในเกม (Gagné 9 เหตุการณ์)

| # | เหตุการณ์ | การนำไปใช้ในเกม |
|---|---|---|
| 1 | กระตุ้นความสนใจ | ฉากเปิด: ยานเอเลี่ยนปล่อยมอนสเตอร์ + เสียงไซเรน |
| 2 | แจ้งวัตถุประสงค์ | "ภารกิจ: ยิงมาตราตัวสะกดให้ถูก เปลี่ยนมอนสเตอร์เป็นมิตร" |
| 3 | ทบทวนความรู้เดิม | ด่าน 1 ฝึกยิงตรงมาตรา (ทบทวนก่อนไม่ตรงมาตรา) |
| 4 | นำเสนอเนื้อหาใหม่ | มอนสเตอร์แสดงคำ + ตัวสะกดกะพริบ (ตัวชี้เป้า) |
| 5 | ชี้แนะการเรียนรู้ | คำใบ้ระดับ 1–2 (ชะงัก + "ออกเสียงเหมือน ก สะกด") |
| 6 | ให้ผู้เรียนปฏิบัติ | ผู้เรียนเลือกกระสุนและยิงเองทุกคลื่น |
| 7 | ให้ผลป้อนกลับ | ถูก/ผิดทันที + เหตุผล "ข = แม่กก (ไม่ตรงมาตรา)" |
| 8 | ประเมินผล | คะแนน/ความแม่นยำ/รายมาตรา บันทึกลง Dashboard |
| 9 | ส่งเสริมการจดจำ/ถ่ายโอน | ด่าน 7–8 คำพ้องเสียงใหม่ + การ์ด AR ใช้ทบทวนนอกเวลาเรียน |

## 5.3 การออกแบบแบบทดสอบก่อน–หลังเรียน (Pre-test / Post-test)

**แบบทดสอบคู่ขนาน 2 ชุด (A/B) — สลับก่อน/หลัง**

| ข้อกำหนด | รายละเอียด |
|---|---|
| จำนวนข้อ | 20 ข้อ (ปรนัย 4 ตัวเลือก) |
| โครงสร้าง | จำแนกมาตรา (8 ข้อ) · ระบุตัวสะกดตรง/ไม่ตรง (8 ข้อ) · เขียนสะกดคำ (4 ข้อ) |
| ระดับ Bloom | จำได้ 30% · เข้าใจ 40% · ประยุกต์ 30% |
| คุณภาพข้อสอบ | ครูภาษาไทย 3 คน ตรวจ IOC ≥ 0.67, ทดลองใช้กับนักเรียน 30 คน, ค่าความยาก p 0.2–0.8, อำนาจจำแนก r ≥ 0.2 |
| ความเชื่อมั่น | KR-20 / Cronbach's Alpha ≥ 0.70 |

> **ตัวอย่างข้อสอบ (ประยุกต์):** "คำในข้อใดมีตัวสะกดอยู่ในมาตราเดียวกับคำว่า **เลข**? ก. มาก ข. วัด ค. ภาพ ง. บ้าน" (เฉลย ก — แม่กก ไม่ตรงมาตรา)

## 5.4 การประเมินระหว่างเล่น (In-game Assessment)

ระบบบันทึก **Learning Analytics** ทุกรอบ (Pinia store + LocalStorage/IndexedDB):

| ข้อมูล | ประโยชน์ |
|---|---|
| คำที่ยิงถูก/ผิด (รายคำ + มาตรา) | Misconception Map รายมาตรา — ครูรู้ว่านักเรียนผิดมาตราไหน |
| เวลาตอบต่อคำ, จำนวนครั้งผิด | วัดความอัตโนมัติ (Automaticity) |
| จำนวนครั้งที่ใช้คำใบ้ | ประเมินความยากของด่าน/ความพร้อมผู้เรียน |
| คะแนน/ดาว/ชิ้นส่วนที่ได้ | แรงจูงใจ + ความก้าวหน้า |
| ประสิทธิภาพโหมด AR | ประเมินการใช้งานจริงของโหมดเสริม |

**Dashboard ครู:** ตารางสรุปห้องเรียน — มาตรา A: ผ่าน 90% · มาตรา กน: ผ่าน 55% ⚠️ → ครูจัดกิจกรรมซ่อมเสริมมาตรา กน

## 5.5 การประเมินแรงจูงใจและความพึงพอใจ

| เครื่องมือ | รายละเอียด |
|---|---|
| **แบบสอบถามแรงจูงใจ (IMMS)** | ดัดแปลง Keller's IMMS — วัด ARCS 4 ด้าน (Likert 5) |
| **แบบสอบถามความพึงพอใจ** | เชิงปริมาณ + ปลายเปิด ("สนุกตรงไหน / อยากได้อะไรเพิ่ม") |
| **สนทนากลุ่มย่อย** | ผู้เรียน 8–10 คน หลังเรียน — ความรู้สึกต่อเกม/คำใบ้/ความยาก |
| **การสังเกตการณ์** | บันทึกความตั้งใจ ความร่วมมือ พฤติกรรมขณะเล่น |
