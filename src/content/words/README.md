## ฟิลด์ของแต่ละคำ

```ts
interface WordEntry {
  id: string;              // รหัส เช่น "KK-001" (รหัสมาตรา-ลำดับ)
  word: string;            // คำเต็ม
  finalConsonant: string;  // ตัวสะกด (อักษรท้าย; "-" = ไม่มีตัวสะกด)
  matra: 'กา'|'กก'|'กด'|'กบ'|'กน'|'กม'|'เกย'|'เกอว';
  regular: boolean;        // true = ตรงมาตรา, false = ไม่ตรงมาตรา
  difficulty: 1|2|3;       // 1 ง่าย, 2 ปานกลาง, 3 ยาก
  source: string;          // แหล่งอ้างอิง
  note?: string;           // หมายเหตุพิเศษ (เช่น คำยืม, การันต์)
}
```

**การใช้ในเกม (บทที่ 7.3):** `Monster.word: WordEntry` — เกมแสดง `word`, สุ่มคำตาม `difficulty`/
`regular` ตามด่าน, ตรวจคำตอบด้วย `matra` เปรียบเทียบกับกระสุนที่ผู้เล่นยิง (แป้น 1–8 = `MATRA_BULLETS`)

## ข้อควรปฏิบัติ

1. **ก่อนนำไปใช้จริง:** ทุกคำต้องผ่านการตรวจ IOC โดยครูภาษาไทย (บทที่ 3.3, 10.2) — คำในไฟล์นี้
   ผ่านการตรวจสอบเชิงระบบ (มาตรา/ตัวสะกด/ตรง-ไม่ตรง) แล้ว แต่ควรให้ครูยืนยันอีกครั้ง
2. **การสุ่มในเกม:** ไม่อนุญาตให้คำซ้ำภายในรอบเดียวกัน (สุ่มแบบไม่ใส่คืนจนกว่าจะครบชุด)
3. **สัดส่วนตามด่าน (บทที่ 3.3):** ด่าน 1–3 ตรงมาตรา 80% · ด่าน 4–6 ผสม 50/50 · ด่าน 7–8 ไม่ตรงมาตรา 70%+
4. **ขยายคำเพิ่ม:** เพิ่มตามฟอร์แมตเดียวกัน แล้วอัปเดต `meta.count` — สคริปต์ตรวจสอบสามารถรันซ้ำได้
   (ตรวจมาตรา/ตัวสะกด/ตรง-ไม่ตรง/ความซ้ำ)
