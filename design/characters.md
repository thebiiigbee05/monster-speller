## 2. ฝ่ายผู้เล่น (ฮีโร่)

### 2.1 นักบินกองกำลังพิทักษ์
- **บทบาท:** ตัวละครผู้เล่น — "ผู้พิทักษ์ตัวสะกด" ลูกเรือคนเดียวของยานผู้พิทักษ์-1
- **บุคลิก:** กล้าหาญ ตื่นตัว ตลกเบา ๆ (ไม่พูดมาก — แสดงผ่าน HUD/เอฟเฟกต์)
- **ปรากฏ:** ไม่มีสไปรต์เต็มตัว (มองจากมุมยาน) — สื่อผ่านยาน + ข้อความสรุปรอบ
- **ในอนาคต (Sprint 5+):** รูปนักบินใน Hangar/Modal ตั้งค่า

### 2.2 ยานอวกาศ "ผู้พิทักษ์-1" (Guardian-1)
- **บทบาท:** ยานผู้เล่น — ยิงกระสุนมาตราตัวสะกด 8 ชนิด
- **ตำแหน่ง:** กลางจอล่าง `SHIP = { x: 480, y: 480 }` (960×540)
- **เอฟเฟกต์:** เปลวท้ายยานสั่นไหว (เขียว-ส้ม), แฟลชปากกระบอกตอนยิง, หางกระสุนเรืองแสง
- **อัปเกรด (Sprint 4 — Hangar):**
  | ชิ้นส่วน | ผล | เงื่อนไข |
  |---|---|---|
  | ปืนเลเซอร์ | ยิงเร็วขึ้น | สะสมชิ้นส่วนถึงเกณฑ์ |
  | โล่พลังงาน | ทนมอนสเตอร์ถึงฐานได้ +1 ตัว | คะแนนรวมถึงเกณฑ์ |
  | เครื่องยนต์ไฮเปอร์ | ยานขยับเร็วขึ้น | ด่าน 5+ |

## 3. ฝ่ายเอเลี่ยนบุก (ศัตรู)

> กำเนิดเรื่อง: ยานเอเลี่ยนขนาดยักษ์ปล่อยมอนสเตอร์ลงสู่โลก — **มอนสเตอร์แต่ละตัวถือบัตรคำศัพท์ที่ขาดตัวสะกด** เมื่อยิงกระสุนมาตรา�ที่ถูกต้อง → เปลี่ยนเป็นมิตร (กลับใจ) ตัวสะกดเต็มคำ

### 3.1 วอล์กเกอร์ (WalkerMonster) — "แม่กก" 🟢
| หัวข้อ | รายละเอียด |
|---|---|
| **ชื่อไทย** | มอนสเตอร์วอล์กเกอร์ (ตัวเขียว) |
| **มาตรา** | แม่กก (ตัวลวงเสียง ก) — คำฝึกพื้นฐาน |
| **สถิติ** | ความเร็ว 45 px/วิ · แต้ม 100 |
| **โอกาเกิด** | 50% (TYPE_ROLL) |
| **หน้าตา** | ตัวกลมสีเขียว หนวด 2 เส้นปลายทอง ตากลม 2 ดวง ปากเล็ก |
| **แอนิเมชัน** | เดิน 4 เฟรม (ขาสลับ+ตัวโยก+หนวดแกว่ง) · ตะลึง (ตา X+ลิ้นห้อย+ดาววน) · ระเบิด 3 · เป็นมิตร 2 (ยิ้ม+แก้มแดง+หัวใจ) |
| **บุคลิก** | เงอะงะ น่ารัก หลงทาง — "มาบุกโลกแต่ลืมตัวสะกด" |

### 3.2 รันเนอร์ (RunnerMonster) — "แม่กด" 🩷
| หัวข้อ | รายละเอียด |
|---|---|
| **ชื่อไทย** | มอนสเตอร์รันเนอร์ (ตัวชมพู) |
| **มาตรา** | แม่กด (เสียง ด) — เพิ่มจังหวะ/ความกดดัน |
| **สถิติ** | ความเร็ว 95 px/วิ (เร็วสุด) · แต้ม 150 |
| **โอกาสเกิด** | 30% |
| **หน้าตา** | ลำตัวเพรียวเอียง ครีบหลัง 3 ตา รองเท้าสีขาว |
| **แอนิเมชัน** | เดิน 4 เฟรม (วิ่งเหยาะ ๆ) · ตะลึง/ระเบิด/เป็นมิตร ครบ |
| **บุคลิก** | เร็ว ใจร้อน ตื่นตระหนกง่าย |

### 3.3 แทงก์ (TankMonster) — "แม่กบ" 🟣
| หัวข้อ | รายละเอียด |
|---|---|
| **ชื่อไทย** | มอนสเตอร์แทงก์ (ตัวม่วง) |
| **มาตรา** | แม่กบ (เสียง บ) — คำที่ผิดบ่อย ให้ฝึกซ้ำ |
| **สถิติ** | ความเร็ว 30 px/วิ (ช้าสุด) · แต้ม 200 · HP สูง |
| **โอกาสเกิด** | 20% |
| **หน้าตา** | ตัวอ้วนกลม หัวแป๊กทอง 2 อัน ตาหงอย (sleepy) ปากเรียบ |
| **แอนิเมชัน** | เดิน 4 เฟรม (หนักหน่วง) · ตะลึง/ระเบิด/เป็นมิตร ครบ |
| **บุคลิก** | เชื่องช้า เซื่องซึม เกราะหนา — ต้องยิงซ้ำ |

### 3.4 ราชามอนสเตอร์ (BossMonster) — "แม่กน" 👑
| หัวข้อ | รายละเอียด |
|---|---|
| **ชื่อไทย** | ราชามอนสเตอร์ (จอมทัพแดง) |
| **มาตรา** | แม่กน (เสียง น) — บอสท้ายด่าน |
| **สถิติ** | ใหญ่สุด · ต้องสะกดถูก **หลายคำติดต่อกัน** (docs 10.1) |
| **โอกาสเกิด** | เฉพาะด่านบอส (4 และ 8 — `boss: true`) |
| **หน้าตา** | เขาทอง 2 เขา คิ้วโกรธ ตาแดง ฟันแหลม |
| **แอนิเมชัน** | เดิน 4 เฟรม (ก้าวใหญ่) · ตะลึง/ระเบิด/เป็นมิตร ครบ |
| **บุคลิก** | ยโส โกรธง่าย — เมื่อถูกสะกดถูกครบ → สำนึกผิด กลายเป็นมิตรนำทัพกลับดาว |

## 6. ตัวละครเสริมที่วางแผน (Sprint 5+)

| ตัวละคร | บทบาท | หมายเหตุ |
|---|---|---|
| **ผู้บัญชาการสถานี** | ตัวละครบอกภารกิจ (ไกด์) — บทสนทนาสั้น ๆ เริ่มด่าน | ต้องการ portrait sprite |
| **หุ่นยนต์ช่วยฝึก (RO-BOT)** | ผู้ช่วยสอน — แสดงคำใบ้/เคล็ดลับในโหมดเรียนรู้ | ใช้แทน hint banner text |
| **เอเลี่ยนเด็ก ๆ** | มอนสเตอร์รุ่นจิ๋ว (บอสพิเศษ AR) — โหมดสแกนการ์ด | ตามสเปก AR cards |
