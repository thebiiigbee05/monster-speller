## 2. บุคลิกและเรื่องราว

> "ยานโจมตีเบา 1 ที่นั่งของหน่วยพิทักษ์ — คล่องแคล่ว ซ่อมง่าย อัปเกรดได้ไม่รู้จบ"

- รวดเร็ว คล่องแคล่ว (ยิงกระสุน 8 มาตรา)
- เป็นสัญลักษณ์ "ผู้พิทักษ์ตัวสะกด" — ไฟนีออนสีมาตรา
- อัปเกรดได้ 4 ชิ้นส่วน (เครื่องยนต์/ปืน/โล่/เซนเซอร์)

## 3. เอกลักษณ์เงา (Silhouette) ⭐ บังคับ

```
     ▲
    ███
   █████       ← ลำตัวสามเหลี่ยมชี้ขึ้น
  ███████
 ██ █████ ██   ← ปีก 2 ข้างยื่น
 ███████████
     ██
    ████       ← เปลวท้ายยาน (เขียว-ส้ม)
```

**กฎ:** สามเหลี่ยมชี้ขึ้น + ปีก 2 ข้าง + แกนกลางสีต่าง = ผู้พิทักษ์-1 (ห้ามสับสนกับยานเอเลี่ยน)

## 4. Shape Language

| หลักการ | ค่า |
|---|---|
| **รูปทรงหลัก** | สามเหลี่ยม/ลูกศรชี้ขึ้น (ล้ำสมัย โจมตี) |
| **สัดส่วน** | กว้าง 44px × สูง 50px (วาดด้วยโค้ด) |
| **เส้น** | เส้นตรงแหลม — เทคโนโลยี, ต่างจากมอนสเตอร์ที่โค้ง |
| **สี** | ฟ้าประจำตัว + ชมพูแกนกลาง (ไฟประจำหน่วย) |

## 5. จานสี (Palette)

| เฉด | hex | ใช้ที่ |
|---|---|---|
| ลำตัวหลัก | `#00e5ff` | ตัวยาน (ฟ้านีออน) |
| แกนกลาง | `#ff2e97` | กระจก/แกนกลาง (ชมพู) |
| เปลวไฟ | `#39ff14` → `#ffb703` | เปลวท้าย 2 ชั้น (เขียว→ส้ม) |
| โครงเข้ม | `#0a1440` | ขอบ/รายละเอียด |

## 6. กฎต้องทำ / ต้องห้าม

**✅ ต้องทำ**
- ลำตัวสามเหลี่ยมชี้ขึ้นเสมอ (ทิศทางยิง)
- เปลวท้ายสั่นไหว (animate — ไม่นิ่ง)
- แฟลชปากกระบอกตอนยิง

**❌ ต้องห้าม**
- ห้ามมีสีเดียวกับมอนสเตอร์ (เขียว `#39ff14` สงวนไว้เปลวไฟเท่านั้น)
- ห้ามเอียง/หมุนเวลายิง (ยานตั้งตรงเสมอ)
