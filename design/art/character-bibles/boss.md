## 2. บุคลิกและเรื่องราว

> "ราชาผู้หลงลืมตัวสะกดตัวเอง — ยโส โกรธง่าย แต่เมื่อสะกดถูกครบก็สำนึกผิด"

- ยโส ถือตัว (คิ้วโกรธตลอด)
- โกรธง่ายมากเมื่อยิงผิด — ต้องสะกดถูก **หลายคำติดต่อกัน** ถึงแพ้
- เมื่อแพ้ → สำนึกผิด นำทัพกลับดาว (ฉากจบ)

## 3. เอกลักษณ์เงา (Silhouette) ⭐ บังคับ

```
     /\    /\
    /  \  /  \     ← เขาทอง 2 เขา โค้งออก
   ▄▄▄▄▄▄▄▄▄▄▄
  █████████████
  ██▄▄▄▄▄▄▄███    ← คิ้วโกรธเข้ม
  ██◉▄▄▄◉██████    ← ตาแดงเข้ม
  █████████████
  ██▄▄▄▄▄▄▄███    ← ฟันแหลม
  █████████████
   ███     ███   ← ขาใหญ่ 2 ขา
```

**กฎ:** ใหญ่สุด + เขาทอง 2 เขา = บอส (ห้ามตัวอื่นมีเขาเด็ดขาด)

## 4. Shape Language

| หลักการ | ค่า |
|---|---|
| **รูปทรงหลัก** | วงรีตั้ง + มุมแหลม (เขา/ฟัน/คิ้ว) — อำนาจ + อันตราย |
| **สัดส่วน** | สูงที่สุด/ใหญ่ที่สุดในฝูง (150px วาด) |

## 6. กฎต้องทำ / ต้องห้าม

**✅ ต้องทำ**
- เขาทอง 2 เขาโค้งออกเสมอ (เครื่องหมายราชา)
- คิ้วโกรธ + ตาแดงเข้ม
- ฟันแหลมเล็ก ๆ 2-3 ซี่
- ตัวใหญ่กว่ามอนสเตอร์อื่นอย่างเห็นได้ชัด

**❌ ต้องห้าม**
- ห้ามตัวเล็ก/กลม/น่ารักเกินไป (ต้องมีพลัง)
- ห้ามน่ากลัวเกินไปสำหรับเด็ก 8–10 ปี (ตลกข่มขู่พอดี)
- ห้ามเปลี่ยนสีหลักจากแดง
