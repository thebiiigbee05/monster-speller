## 2. บุคลิกและเรื่องราว

> "ยานเกราะตัวอ้วนกลม เซื่องซึม — เกราะหนาเพราะไม่เคยวิ่งหนีใคร"

- เชื่องช้า เซื่องซึม ง่วงตลอดเวลา (ตาหงอย)
- เกราะหนา — ต้องยิงซ้ำ/สะกดซ้ำถึงจะแพ้
- เมื่อถูกสะกดถูก → ตื่นเต้นครั้งแรกในชีวิต ยิ้มกว้าง

## 3. เอกลักษณ์เงา (Silhouette) ⭐ บังคับ

```
    ▄▄▄▄▄▄▄▄
   ██████████    ← ตัวอ้วนกลมกว้างที่สุดในฝูง
  ████████████
  ████◡  ◡████    ← ตาหงอยครึ่งหลับครึ่งตื่น
  ████████████
  ████████████
   ▀▀▀▀▀▀▀▀▀▀
    ██     ██   ← ขาสั้นมาก (เกือบติดพื้น)
```

**กฎ:** เงากว้างกลมที่สุด + หัวแป๊กทอง 2 อันบนหัว = แทงก์ (กว้างกว่าทุกตัว)

## 6. กฎต้องทำ / ต้องห้าม

**✅ ต้องทำ**
- ตัวกลมกว้างที่สุด — มองแล้วรู้สึก "หนัก"
- หัวแป๊กทอง 2 อันบนหัวเสมอ (สกรู/หมุด)
- ตาหงอยครึ่งหลับครึ่งตื่น (sleepy)
- ขาสั้นมาก เดินช้า กระแทกพื้น

**❌ ต้องห้าม**
- ห้ามตัวเพรียว/เอียง (รันเนอร์)
- ห้ามตาโตกลม (วอล์กเกอร์)
- ห้ามมีเขาหรือคิ้วโกรธ (บอส)
- ห้ามเปลี่ยนสีหลักจากม่วง
