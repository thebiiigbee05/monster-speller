## 📋 3 ชั้นคืออะไร

| ชั้น | คำถาม | เนื้อหา | ใช้ใคร |
|---|---|---|---|
| **1. Bible** | "เป็นใคร" | บุคลิก, เงาเอกลักษณ์, สี, กฎห้าม | นักเขียนบท/แอนิเมเตอร์/การตลาด |
| **2. Sheet** | "หน้าตา" | เทิร์นอราวด์ 4 มุม, ท่า, ตารางสี, micro-details | นักวาดสไปรต์ |
| **3. Sprite spec** | "ขยับยังไง" | timing/pivot/hitbox ต่อเฟรม | โปรแกรมเมอร์/เอ็นจิน |

## 🚦 ขั้นตอนเพิ่มตัวละครใหม่

1. คัดลอก `character-bibles/_TEMPLATE.md` → เติมข้อมูล (เอกลักษณ์เงา/สี/กฎ)
2. ตรวจ silhouette ไม่ซ้ำตัวเดิม
3. คัดลอก `character-sheets/_TEMPLATE.md` → วาดเทิร์นอราวด์ + ตารางสี
4. เพิ่มแถวใน `sprite-spec.json` (timing/pivot/hitbox)
5. วาดสไปรต์จริง (หรือใช้พรอมต์บท 15.8) → ใส่ sheet → แจ้งโปรแกรมเมอร์

## ✅ มาตรฐานบังคับทุกตัวละคร

- [ ] จำได้จาก **เงาล้วน** (Silhouette test)
- [ ] สี 1 หลัก + 2 รอง + โครง 1 สี (จากจานธีม 6 สี)
- [ ] น่ารัก/ตลก — เหมาะเด็ก 8–10 ปี (ไม่มีน่ากลัวจริง)
- [ ] Bounding box ตรง spec · 4 มุมสัดส่วนเท่ากัน (กัน jitter)
- [ ] รายละเอียดเฟรม timing/pivot ตรง `sprite-spec.json`

> เอกสารชั้น 1–2 เป็น **สเปก** (ข้อตกลง) — ไฟล์ภาพจริง (png/aseprite)
