# 🔍 sprite-frame-detect.py — ตรวจจับขอบเฟรม Sprite Sheet อัตโนมัติ

> แก้ปัญหาที่ AI สร้าง sprite sheet แบบ **ไม่มีกริดตายตัว**: เฟรมไม่เท่ากัน,
> ขอบไม่ชัด, พื้นหลังไม่โปร่งใส — ตัดด้วย "สมมติกริดเท่ากัน" จะเหลื่อมเฟรม
>
> สคริปต์นี้ **scan พิกเซลจริง** หาช่องว่าง (gap) แล้วคำนวณพิกัด (x,y,w,h)
> ของทุกเฟรม — ทำงานกับเฟรมขนาดไม่เท่ากันได้

## รองรับ 2 โหมดพื้นหลัง

| โหมด | ตรวจจับได้เมื่อ | วิธีทำงาน |
|---|---|---|
| **transparent** | ภาพมี alpha และมุมภาพโปร่งใส (≥3 จาก 4 มุม) | หาแถว/คอลัมน์ที่ไม่มีเนื้อ (alpha ≤ 8) |
| **bg_color** | ภาพพื้นทึบสีเดียว (เช่น AI ให้พื้นขาว/ดำ) | ใช้สีมุมซ้ายบนเป็น bg → หาแถว/คอลัมน์ที่เป็น bg ล้วน |

## วิธีรัน

```bash
# ครั้งแรก: สร้าง venv + ติดตั้ง Pillow (ทำครั้งเดียว)
cd monster-speller-src
python -m venv .venv-scripts
./.venv-scripts/Scripts/python.exe -m pip install pillow

# ตรวจจับเฟรม (แสดงบนจอ)
./.venv-scripts/Scripts/python.exe scripts/sprite-frame-detect.py <sheet.png>

# บันทึกเป็น JSON (รูปแบบเดียวกับ monsters-sheet.json)
./.venv-scripts/Scripts/python.exe scripts/sprite-frame-detect.py <sheet.png> --out frames.json
```

## พารามิเตอร์

| flag | ค่า default | ความหมาย |
|---|---|---|
| `--threshold` | `0.15` | สัดส่วนความเข้ม (เทียบ peak) ที่ถือว่าเป็น "เนื้อ" — ลดลงถ้าภาพจาง/รายละเอียดน้อย |
| `--min-gap` | `1` | ช่องว่างขั้นต่ำ (px) ระหว่างเฟรม — `0` = ไม่รวมเฟรมที่ชิดกัน |

## ตัวอย่างเอาต์พุต (sheet ของเกมเรา — 40 เฟรม 4×10)

```json
{
  "sheet": "public/assets/sprites/monsters-sheet.png",
  "cellW": 42, "cellH": 60,
  "rows": 4, "cols": 10,
  "backgroundMode": "transparent",
  "frames": [ { "x": 14, "y": 8, "w": 38, "h": 54 }, ... ]
}
```

> หมายเหตุ: พิกัดที่ได้คือ **bounding box ของเนื้อจริง** (ไม่รวม padding)
> — ต่างจาก monsters-sheet.json ที่ใช้กริด 64×64 ของสคริปต์วาดของเรา
> กรณี AI sheet: ใช้พิกัดนี้ตรง ๆ ได้ หรือเพิ่ม padding ให้เท่ากันก่อนใช้กับ SpriteRenderer

## ทดสอบแล้ว

| กรณี | ผล |
|---|---|
| `monsters-sheet.png` (กริดชัด, โปร่งใส) | ✅ 40 เฟรม 4×10 |
| sheet AI จำลอง (พื้นทึบ, เฟรมไม่เท่ากัน 80/60/70/70px) | ✅ 6/6 เฟรมถูกตำแหน่ง |
| เฟรมชิดกัน (gap 4px) | ✅ แยกได้ถูกต้อง |
| เฟรมขนาดต่างกันในแถวเดียวกัน | ✅ จับ bounding box ต่อเฟรม |

## ข้อควรระวัง (ใช้กับผลลัพธ์ AI จริง)

1. **AI มักใส่เงาใต้ตัว** → เงาจะติดไปใน bounding box → ตัดเงาออกก่อน หรือยอมรับ padding ล่าง
2. **พื้นหลังไม่ใช่สีเดียว** (ไล่เฉด/เกรน) → ใช้โหมด transparent; ถ้าไม่มี alpha ให้ใช้
   `--threshold` ต่ำลง หรือทำ background removal (เช่น rembg) ก่อน
3. **เฟรมทับกัน/ซ้อนกัน** (AI วาดทับ) → สคริปต์แยกไม่ออก — ต้องตัดด้วยมือ/แยกภาพก่อน
4. **ตรวจด้วยสายตาเสมอ** — รัน `--out` แล้วเปิดภาพ + พิกัดเทียบ
